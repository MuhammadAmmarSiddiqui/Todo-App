## Summary

Implement a command-line todo application with in-memory storage that allows users to perform CRUD operations on tasks (Add, View, Update, Delete) and mark tasks as complete/incomplete. The application will follow a layered architecture with clear separation between the CLI interface, service layer, and data models, using argparse for command-line parsing and strict type hinting throughout.
